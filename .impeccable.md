## Design Context

### Users
- Primary users are event platform members, including students, organizers, and related participants who manage registrations, attendance, passes, and certificates.
- They use dashboard pages for fast, repeat tasks and need clear status, quick actions, and low-friction navigation.

### Brand Personality
- Professional, trustworthy, and organized.
- Emotional goal: users should feel confident, in control, and informed while managing event activity.

### Aesthetic Direction
- Light-first interface with strong dark-mode support.
- Clean, structured visual language that matches the existing site style.
- Avoid neon colors, heavy gradients, and excessive card clutter.

### Design Principles
1. Clarity before decoration: surface key actions and status first, remove visual noise.
2. Consistent system feel: reuse shared tokens, spacing rhythm, and component patterns.
3. Purposeful hierarchy: one primary focal area per section with clear secondary information.
4. Responsive by adaptation: preserve full functionality on mobile through layout changes, not feature removal.
5. Accessible interactions: visible focus states, readable contrast, and predictable navigation flows.
